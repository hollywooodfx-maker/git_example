## 6. Код

### Инлайн-код

В Python функция `print()` выводит текст на экран.

### Блок кода без подсветки

```
обычный текст
без подсветки синтаксиса
```

### Блок кода с подсветкой

```python
def greet(name: str) -> str:
    return f"Привет, {name}!"

print(greet("Мир"))
```

```sql
SELECT id, name
FROM users
WHERE active = 1
ORDER BY name;
```

```c
#include <stdio.h>

int main(void) {
    printf("Hello, world!\n");
    return 0;
}
```

## 12. HTML-теги в Markdown

Markdown поддерживает часть HTML:

- Перенос строки: `<br>`
- Горизонтальная линия: `<hr>`
- Жирный: `<b>текст</b>`
- Курсив: `<i>текст</i>`
- Подчёркнутый: `<u>текст</u>`

## 13. Комбинирование элементов

### Список с кодом и таблицей

1. Установить зависимости:

   ```bash
   pip install fastapi uvicorn
   ```

2. Запустить сервер:

   ```bash
   uvicorn main:app --reload
   ```

3. Проверить эндпоинты:

   | Метод | Путь      | Описание       |
   |-------|-----------|----------------|
   | GET   | `/`       | Главная        |
   | GET   | `/items`  | Список элементов |
   | POST  | `/items`  | Создать элемент |
